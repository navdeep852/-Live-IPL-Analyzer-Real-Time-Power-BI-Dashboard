Live IPL Analyzer – Power BI Dashboard
Live IPL Analyzer is a dynamic Power BI dashboard that delivers real-time insights into the Indian Premier League (IPL) using live data fetched from the Ultimate Cricket API. The dashboard covers all major aspects of the tournament, including team standings, player stats, match schedules, and live scorecards.

Key Features:

Real-time data integration using API

Multiple analytical pages: Home, Overview, Points Table, Squads, Most Runs, Most Wickets, Wicketkeeper Records, Schedule, Live Scorecard, and Captain List

Interactive visuals powered by DAX, HTML, and CSS

Designed for data professionals and recruiters as a portfolio showcase

Published via Power BI Service for web access

Tools & Technologies:

Power BI Desktop & Service

DAX & Power Query

Ultimate Cricket API (Free Tier)

HTML/CSS Custom Visuals

Purpose:
This project was built as a data storytelling case study to demonstrate real-time data handling, dashboard design, and domain-relevant analytics in sports.
